# Care Guide submission checklist

**Employer instructions:** reply **all** to the original October 27, 2026 recruitment email. Ensure `apply@careguidebd.com` remains in recipients. Five-day deadline: submit as early as possible; do not assume an exact cutoff time without confirmation.

## Deliverables / evidence

- [ ] Live frontend URL opens in incognito; securely share the reviewer password separately, not in a public GitHub file.
- [ ] Live FastAPI health works, unauthorized document route returns 401, authorized reviewer login works.
- [ ] Upload and extraction of synthetic CSV, digital PDF, scanned PDF, image, and Excel demonstrated or accurately marked unverified.
- [ ] GitHub repository link is accessible and `README.md` describes **current** implementation, not Phase 1A.
- [ ] Architecture diagram and DB schema are in `docs/`.
- [ ] Backend/frontend automated test results are included and any skipped tests described.
- [ ] Labeled extraction evaluation is actually run; `evaluation/results/live-evaluation.md` and `.json` are saved and reviewed. If unrun, describe missing measures candidly.
- [ ] Recorded video walkthrough is uploaded and independently accessible.
- [ ] AI-assisted development disclosure and representative prompts are linked.
- [ ] Updated CV lists institution, program, completion year and result; work organizations, positions, responsibilities and employment periods.
- [ ] Two genuine **professional** references: academic supervisor/department head + former company HR representative, with permission and real **official organization email addresses**. Do not invent titles/emails or use personal references.
- [ ] Portfolio with relevant work samples (screenshots, demos, projects) has a working share link.
- [ ] Any missing requirements (semantic search, cross-document reconciliation, production persistence) are disclosed clearly, not described as complete.
- [ ] Reply All on the original mail thread and include all links, attachments, and `apply@careguidebd.com`. Verify the **sent** message retains the right recipients and attachments.

## Suggested final attachment/link bundle

1. Updated CV PDF.
2. Portfolio URL or PDF with 2–4 relevant projects, including this deployed app.
3. GitHub repository URL.
4. Live Vercel demo URL and privately shared password, with warning to use synthetic documents only.
5. `docs/architecture.md` and `docs/database-schema.md` through the repository.
6. `evaluation/results/live-evaluation.md` (generated by actual execution) or accurately qualified preliminary evaluation.
7. MP4 walkthrough or accessible Drive link.
8. `docs/ai-assisted-development.md` and the `docs/` folder.

**Privacy:** do not attach `.env`, SQLite DB files, uploaded invoices, API keys, token, stack trace containing secrets or private company information.
